# Fendomental-analysis

מערכת standalone לניתוח פונדמנטלי יומי ומייצרת תחזית כיוון (Bias) ל-NQ, עם בדיקה
עצמית מול המחיר בפועל וסטטיסטיקת הצלחה שקופה.

**שלב נוכחי: איפיון בלבד, ללא קוד.** ראו [`SPEC.md`](./SPEC.md) למסמך האיפיון המלא —
סכמת DB, מבנה מודולים, ממשקים פנימיים, פרומפט ה-Synthesis Engine, לוגיקת סיווג
Bullish/Bearish/Sideways, ותזמון ה-jobs (שעון ישראל + מעבר קיץ/חורף).
